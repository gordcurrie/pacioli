# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/gordcurrie/pacioli/security/advisories/new) or email [gord@gordcurrie.com](mailto:gord@gordcurrie.com).

Include a description of the issue, steps to reproduce, and potential impact. I'll respond within 7 days.
